Download the template (a header row and one example row).

A row is matched to an existing identity by name and system: a match is updated, anything else is created. Rows are rejected, never coerced, on an unknown system, an unknown owner email, an invalid enum value, a bad date, a missing required cell on a new identity, or a changed type on an existing one. On an update a blank cell leaves the stored value as it is.

Enum values are the stored ones: type service_account, api_key, oauth_grant, webhook, deploy_key, certificate, ci_token, ai_agent; environment prod, staging, dev; privilege_level read, write, admin; storage_location vault, config_file, env_var, source_code, chat_or_ticket, unknown. Dates are YYYY-MM-DD. Lists (events, san, tool_list) are comma separated. No column carries a secret value.
